Web Security Project

Secure Web Application Development & Penetration Testing Project using Node.js, Express.js, and OWASP Juice Shop.

This repository contains weekly tasks completed during a Web Security and Penetration Testing internship/project.

The project focuses on:

- Secure Web Application Development
- Authentication & Session Security
- HTTPS Implementation
- CSRF Protection
- Rate Limiting
- Security Logging & Monitoring
- Basic Penetration Testing
- OWASP Juice Shop Practice

 Repository Structure
